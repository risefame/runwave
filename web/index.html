GPS выкл

Выйди за границу своей территории, сделай дугу и вернись к границе — площадь внутри дуги станет твоей.

Держи экран включённым, при желании убавь яркость. Версия для фоновой записи появится позже.

Доступ к геолокации закрыт

iPhone: Настройки → Конфиденциальность и безопасность → Службы геолокации — включи их, затем разреши доступ для Safari (или браузера, где открыт Runwave) и обнови страницу.

Android: Настройки → Приложения → Браузер → Разрешения → Местоположение.

Android: Настройки → Приложения → Runwave → Разрешения → Местоположение — разреши доступ и вернись в игру.

iPhone: Настройки → Runwave → Геопозиция → При использовании программы, затем открой игру снова.

Геолокация недоступна

На этом устройстве нет геолокации, а Runwave работает только с реальным GPS. Открой игру на телефоне или включи геолокацию в системе.

В режиме разработчика имитацию можно включить в настройках.

В помещении GPS ищет дольше. Подойдите к окну или выйдите на улицу.
