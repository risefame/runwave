# Проект: Runwave, беговая игра (захват территорий)
Структура: web/ (Vite, TypeScript, MapLibre, turf; боевая версия на Cloudflare). Позже: supabase/, mobile/.
Правила:
- Делай только то, что просят в текущей задаче.
- Не читай весь проект, спрашивай нужные файлы.
- Не создавай лишних файлов и документации.
- Ключи только в .env, не показывать.
- Логику игры (захват, фильтр GPS) не менять без явной просьбы.
